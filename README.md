# StockCommerce - Gerenciador de Estoque e Pedidos para Comércios

O **StockCommerce** é um sistema web simplificado desenvolvido para otimizar a gestão de estoque, controle de entradas de mercadorias e emissão de pedidos de venda para micro e pequenos comerciantes.

Projeto desenvolvido para a disciplina de **Prática Profissional em Análise e Desenvolvimento de Sistemas** da **Universidade Presbiteriana Mackenzie**.

* **Backend:** Node.js / Express (API REST)
* **Frontend:** HTML5, CSS3, JavaScript / React SPA
* **Banco de Dados:** PostgreSQL 15
* **Gerenciamento de Dependências:** NPM
